# Open-source-whisper-flow
Just a normal STT app<br>
**Note:** Requires Nvidia GPU<br>
To run just go to command prompt and paste "python stt.py"<br>
Then you can choose the wisper model you want and it will run <br>
The configured hotkey is Alt+S. You must hold it while speaking then release for model to process and start proceesing and typing.<br>
It will automatically pull the whisper model and run
